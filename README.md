# FoxyVPN Master Suite v2.0 (Universal)

کلاینت بهینه‌سازی‌شده، امن و مستقل زیرساخت VPN فایرفاکس و لبه‌های Anycast فستلی:

## امکانات کلیدی:
1. **بالانسر چند اکانته (Multi-Account Hot-Swap)**: رفع قطعی محدودیت ۵۰ گیگابایت با استخر سهمیه نامحدود.
2. **ضد مسمومیت DNS و DPI**: اتصال مستقیم به IPهای تمیز Anycast فستلی برای رفع دائمی ارور CERTIFICATE_VERIFY_FAILED.
3. **کیل‌سوییچ لایه کرنل و مسدودسازی IPv6**: مسدودسازی ۱۰۰٪ هرگونه نشت تصادفی ترافیک.
4. **اسپلیت تونلینگ هوشمند**: مسیریابی مستقیم سایت‌ها و درگاه‌های بانکی ایران.
5. **اد‌بلاکر DNS Sinkhole**: صرفه‌جویی ۳۵ تا ۴۰٪ در مصرف سهمیه ترافیک.
